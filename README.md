# SmsKIT WA Button

SmsKIT WA Button by SmsKIT WA Button.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/69036990129fbce77d4cba77/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **SmsKIT WA Button** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/69036990129fbce77d4cba77/releases/latest) and reinstall.
